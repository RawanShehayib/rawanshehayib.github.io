# rawanshehayib.github.io
Personal Portfolio 

A single-page portfolio built with plain HTML/CSS/JS — no build step, deploys straight to GitHub Pages.

## Deploying to GitHub Pages
1. Create a new repo named `yourusername.github.io` (replace with your actual GitHub username).
2. Copy the contents of this folder (`index.html` and `assets/`) into the repo root.
3. Commit and push to the `main` branch.
4. In the repo, go to Settings → Pages → set source to the `main` branch.
5. Your site will be live at `https://yourusername.github.io` within a few minutes.

## Editing content
Everything lives in `index.html` — bio, projects, skills, and contact info are all plain HTML, no templating.
To swap in real project photos, drop images into `assets/images/` and update the `<img src="...">` paths
(there are two placeholder project cards — MetoyerLab, Peters Lab, and Kyutech — waiting for photos).

## Structure
- `index.html` — the whole site
- `assets/images/` — project photos
- `assets/docs/` — downloadable PDFs (e.g. the CHARMS technical report)
